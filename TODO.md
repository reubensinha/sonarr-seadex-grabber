## Release Infrastructure

- [x] Alpha v0.1.0 release prep: Docker/README cleanup + GitHub Actions CI/CD. Fixed `docker-compose.yml`'s environment block (was hardcoding literal placeholders instead of `${VAR}` substitution, so `.env.docker` silently did nothing); consolidated `config.yaml.example`/`config.yaml.template` into one file; untracked the accidentally-committed `data_BACKUP/`; added an explicit "config.yaml is optional" callout to DOCKER.md (every setting checks its env var first). Also fixed a real bug found while documenting the bare-metal path: `python-dotenv` was a declared dependency but never actually called anywhere, so a `.env` file did nothing for `python main.py` - wired up `load_dotenv()` in `core/config.py` (never overrides a real env var already set, so Docker deployments are unaffected). Restructured ReadMe.md to lead with the Docker quick-start (the intended way to run this) instead of the bare-metal steps - includes a real, copy-pasteable `docker-compose.yml` (not just a pointer to DOCKER.md), so people who never clone the repo (just pull the published GHCR image) have something to start from. Also caught and documented a real gotcha while writing it: `WEBHOOK_HOST` defaults to `localhost` (app-level default, meant for bare-metal), which is unreachable from outside a container - `docker-compose.yml` already hardcodes `0.0.0.0` for you, but it's called out explicitly now since it silently breaks a bare `docker run` otherwise (confirmed by hitting it myself during verification). DOCKER.md's environment variable reference corrected to match. Added a `tests/` smoke-test suite (pytest) covering `main.py`'s scoring, merge/chosen/preferred logic, and grouped-release siblings, plus `ruff` for linting (`pyproject.toml`). New `.github/workflows/ci.yml` (lint + test on every PR into `main`) and `.github/workflows/release.yml` (on merge to `main`: re-runs lint/test, computes the next `vX.Y.Z` tag via `.github/scripts/bump_version.py` - patch by default, minor/major via a `bump:minor`/`bump:major` PR label, `v0.1.0` seed if no tags exist yet - pushes the tag, builds and publishes to `ghcr.io/reubensinha/sonarr-seadex-grabber` as `vX.Y.Z` + `latest`, and creates a GitHub Release).
